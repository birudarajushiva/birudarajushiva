I build interactive software, AI-assisted tools, and hardware projects. My interests sit where software engineering meets physical systems: inspectable AI workflows, 3D interfaces, embedded electronics, and robotics.

## Selected projects

### Morf · conversational 3D design
Explore physical assemblies, ask how parts work, and review proposed changes alongside source references and supported geometry checks. Built with TypeScript, Next.js, React, Three.js, and server-side Gemini integration.

The engineering focus is preserving a shared assembly document across conversation, scene interactions, proposal review, and undo/redo. Includes a separate circuit workbench. **Source is private.** Design checks are scoped software studies; physical hardware and manufacturing readiness are not established.

### Jarvis on Jetson · local AI tooling
A Python coding-agent controller for NVIDIA Jetson using local Ollama inference, bounded Docker execution, tests, and a separate publishing workflow. Includes repository-job automation and an allowlisted browser tool.

The engineering focus is making tool execution and review boundaries explicit. **Source is private.** This is a local AI systems project; autonomous robot operation is not claimed.

### [Verdict](https://github.com/birudarajushiva/verdict) · evidence exploration
A TypeScript/React prototype that explores evidence for and against an argument using seeded graph traversal and model-assisted specialist tasks. The interface exposes support/refute paths and reviewer challenges.

**Look for:** shared API contracts, separated processing stages, and reproducibility tests. Scores are application heuristics, not calibrated truth estimates.

### [Aligned](https://github.com/birudarajushiva/aligned) · memory-grounded AI outreach
A Python/FastAPI prototype combining deterministic account scoring, EverOS retrieval, and Gemini-generated drafts. Retrieved memory remains visible for inspection.

**Look for:** explainable rules, provider-failure handling, and explicit offline replay. Accounts and revenue examples are simulated; no customer impact is claimed.

### [HackPad](https://github.com/birudarajushiva/HackPad) · embedded hardware
An eight-key macropad design with a rotary encoder and OLED, created for Hack Club's Blueprint mission. Includes KiCad PCB/schematic source, enclosure CAD, and CircuitPython firmware.

**Look for:** the path from electronics and enclosure design to firmware. The prototype has documented pin-allocation and HID issues requiring hardware validation.

## What I care about

- **Software engineering:** clear contracts, reproducible setup, inspectable state, and useful tests.
- **AI systems:** evidence grounding, honest failure states, and explicit boundaries around generated output.
- **Robotics and embedded systems:** connecting software with geometry, electronics, and physical constraints.
- **Hackathon work:** turning an idea into a demonstrable prototype while being clear about what works and what remains unverified.

The portfolio links above distinguish public source from private work. Project documentation records prototypes, source attribution, and verification limits.
